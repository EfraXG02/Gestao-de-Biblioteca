# 📚 Sistema de Gestão de Biblioteca (Windows Forms)

Um sistema completo de simulação para gerenciamento de biblioteca desenvolvido em **C#** utilizando **Windows Forms**. O projeto abrange desde a consulta pública de acervo por alunos até o controle administrativo de estoque, cadastros e aprovação de empréstimos.

---

## 🚀 Funcionalidades

### 👨‍🎓 Módulo do Aluno / Usuário
- **Cadastro de Alunos:** Registro de novos usuários no sistema.
- **Consulta de Acervo:** Pesquisa rápida e dinâmica de livros por **Nome** ou **ID**.
- **Solicitação de Empréstimo:** O aluno pode solicitar o livro desejado diretamente pelo sistema.
- **Geração de Comprovante:** Quando o empréstimo é aprovado pelo administrador, o sistema gera um **código único** para retirada do livro na biblioteca física.

### 🛡️ Módulo do Administrador (ADM)
- **Acesso Restrito:** Autenticação via senha administrativa (Senha padrão de simulação: `2026`).
- **Gestão de Acervo (CRUD):** Adicionar novos livros e remover livros do catálogo.
- **Central de Aprovações:** Visualizar e aceitar/recusar solicitações de empréstimo pendentes.

---
